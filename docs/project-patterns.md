# 从真实研究问题提炼的可复用设计模式

本页把两类研究过程抽象为实践模板：**如何控制学习更新**，以及**如何组织表示、记忆与内部计算**。它们是设计建议与数学诊断，不是本仓库新完成的算法效能结果；不包含原项目数据、运行身份或未公开数值。读者可以替换自己的候选算法和任务，但应保留问题、对照和撤回条件。

## 1. 先拆开基础方向与学习控制器

把一次实际写入表示为 `Δθ = Cψ(b, history)`。`b` 包含真正执行的资格迹、归一化、熵项和优化器处理，不能拿裸梯度代替。控制器可能只调尺度，也可能改目标、方向、更新时钟或数据选择。

对于正对角缩放 `Δθ = D b`，其中 `0 < lᵢ ≤ dᵢ ≤ uᵢ`，在**同一次已固定事件**上复现目标向量 `v` 的充要条件为：

- 若 `bᵢ = 0`，则 `vᵢ = 0`；
- 若 `bᵢ ≠ 0`，则 `vᵢ / bᵢ ∈ [lᵢ, uᵢ]`。

这是直接代数结论。若倍率由少量共享元参数生成，还需满足共享函数类限制。正倍率能改变各坐标相对幅度，但不能翻转该事件某个非零坐标的符号。另一方面，条件倍率会改变 `E[Dₜbₜ]`；**单次写入不可达不等于长期策略不可达**。等参数范数也不等于等策略 KL。

实用四格：

| | 固定率 | 自适应率 |
|---|---|---|
| 原始学习算子 | 基座参照 | 控制器增量 |
| 替代学习算子 | 算子增量 | 两者交互 |

共同基座机制面板回答“是哪项改变起作用”；完整作者方法面板回答“新方法有无竞争力”。例如比较精英动作投影与策略梯度时，要保留候选分布、Q 评价、采样成本和 replay 制度的区别，不能只把学习率换个名字。[GreedyAC](https://arxiv.org/abs/1810.09103v4)、[Intentional Updates](https://arxiv.org/abs/2604.19033) 提供了不同的更新控制视角。

**停止条件：** 控制器无法表达所需写入时，增加控制器训练步数不能解决这个固定函数类缺口；若换算子有效而自适应率无增量，归功于算子，并保留阴性对照。

## 2. 旧导数正确，不代表当前修改有用

历史元导数回答过去某个参数变化如何影响既有轨迹或指定目标。部署时更直接的问题是：在当前完整学习状态 `Lₜ` 中，执行修改 `u` 后，未来继续学习是否获得更多原始回报？

定义一个诊断目标：

`Aᴴ(Lₜ,u) = E[Σₖ₌₀ᴴ⁻¹ rₜ₊ₖ | do(u), 后续学习程序固定] − E[Σₖ₌₀ᴴ⁻¹ rₜ₊ₖ | do(0), 同一后续规则]`。

`Lₜ` 应包含网络、优化器、资格迹、归一化、replay/记忆与随机状态；环境隐状态可以用于隔离模拟诊断，但不是免费部署输入。固定策略的 `Qπ` 与“继续学习的程序价值”是不同对象。有限 `H` 可能漏掉 critic 修改更晚发生的收益。

建议分开测：导数数值一致性、实际写入是否发生、方向、幅度、当前修改价值、完整生命期收益。固定长度归一化可能改变“修改强度与效用相关”的权重，因此同时保留原始修改、同长度替代方向和固定幅度对照。不能从“写入非零”直接跳到“元学习有效”。[Metatrace](https://www.ijcai.org/proceedings/2019/581) 是在线元步长的先行方法；其目标与新定义的程序继续价值需逐式区分。

**停止条件：** 先在预定跨度、年龄、初始化和候选动作集合上发现可辨识的机会，再扩大元模型。树枝与时间窗口依赖同一个根/生命期，不计作独立种子。精确分支诊断不提供真实部署中的免费反事实。

## 3. 加信息前先排除共同偏置

当一个简单共同动作在所有已测根上都最好时，复杂状态读出在该有限菜单中的增量机会可能很小。先比较多个基础率、训练年龄、初始化、正负修改和不修改；不要只比较一个有利方向后宣称“信息无用”。

信息机会、函数类表达、估计噪声、学习优化和部署分布变化是五个不同环节。隔离诊断中可使用准确值或完整历史寻找信息上限；若用于在线算法，则必须另给合法经验估计式、反馈时点和成本。未经证明的强 oracle 不叫数学上界。

**停止条件：** 调好简单固定基率后增益消失，则撤回“更复杂信息必要”的解释；若只有单初始化的小树增量，先做独立根人口确认，不直接启动大规模神经实验。

## 4. 强外部基线和内部消融同时存在

在严格 streaming actor–critic 的学习控制研究中，一个有针对性的起始面板是 **Stream-AC、Metatrace、Intentional-AC**，再加候选方法；其他课题应选择其最强且制度相容的先行方法，而非把这三者当所有 RL 的通用名单。

| 基线身份 | 保留什么 | 能支持什么 |
|---|---|---|
| 作者完整方法 | 真实网络、目标、归一化、优化器、超参语义 | 同信息与资源制度下的整体竞争力 |
| 明示的方程移植 | 原方程与所有适配差异 | 该移植在当前接口中的表现 |
| 同基座内部消融 | 指定主改动以外的组件 | 机制归因 |

作者完整方法不应为了“匹配”被改写成候选的网络与优化器；归因另做共同基座。Intentional 的功能单位 `eta` 与 SGD 学习率不应按相同数值配对；Intentional-Q 不改名为 Intentional-AC。Stream-X 的 2024 与 2026 源码应绑定各自版本。[Stream-X 作者仓库](https://github.com/mohmdelsayed/streaming-drl)、[Metatrace 正式论文](https://www.ijcai.org/proceedings/2019/581)、[Intentional 作者仓库](https://github.com/sharifnassab/Intentional_RL)。

**停止条件：** 指定强面板未完成，就不作完整方法优越结论。方法的某中心配置失败时保留失败；修复数值问题属于新版本，不能抹掉原尝试再宣布“同一方法全部成功”。

## 5. 表示、记忆、计算与通信分开测试

将状态拆成当前观测编码 `zₜ`、跨步记忆 `mₜ`、当前动作内工作状态 `wₜ`、慢参数 `θₜ`、学习器统计 `qₜ`。冻结 `θ` 并不等于没有学习：`m` 或外部库仍可写入新关联。反之，参数变化也不自动表示有用的新知识形成。[RL²](https://arxiv.org/abs/1611.02779) 展示了慢参数与快速状态适应的区别。

| 主张 | 必备对照 | 易混淆量 |
|---|---|---|
| 编码本身更易学习 | 原 MLP、活跃参数匹配 MLP、固定随机特征、候选编码 | padded 零坐标不提供活跃容量 |
| 更好记住过去 | 无记忆、短历史、EMA、自连接、普通门控 RNN | EMA 稳态幅度、隐藏状态大小、输入权限 |
| 额外内部计算有效 | 同一记忆 + 单层头、共享循环头、等计算深头 | 跨步记忆与动作内重复写入同时改变 |
| 选择性通信有效 | dense、self-only、随机稀疏、匹配稀疏、内容选择消息 | 读出层或全局输入仍提供跨模块通路 |
| 结构先验有效 | 参数/度数/符号/强度匹配重连与普通图 | 图指标改善但实际功能无变化 |
| 可塑性维护有效 | 原基座、简单正则、重置统计、重置单元、候选维护 | 清陈旧优化状态与选中特定单元的贡献 |

分开报告参数数、活跃参数、持久状态字节、峰值内存、前向与学习 FLOPs、延迟。等参数和等计算往往无法同时做到，应各有面板而非声称唯一“公平”。不要人为切掉普通 RNN 的信息路径来制造优势。[StreamRTU](https://arxiv.org/abs/2605.24709v2)、[Continual Backpropagation](https://www.nature.com/articles/s41586-024-07711-7) 是相关直接对照来源，移植资格另验。

**停止条件：** 只赢小网络、不赢活跃容量控制，不归因于编码；只赢浅头、不赢等计算深头，不归因于共享循环；干扰下降同时迁移受损，不称更好的共享。

## 6. 学习影响要测最终写入

激活相似、图模块度或参数距离只是候选诊断。局部功能变化取决于实际写入：`Δf(h′) ≈ Jθ(h′)Δθ`，若可写记忆也改变，应增加对应项或直接做有限干预。对旧输出梯度子空间做投影后再施逐坐标缩放，一般会破坏原来的正交关系；资格迹也改变最终方向。[OGD](https://proceedings.mlr.press/v108/farajtabar20a.html) 提供了投影方法的公开参照。

同时测相关经验迁移、冲突经验干扰、长期原始回报。维护或替换循环单元时登记权重、hidden、敏感度、资格迹、优化器和归一化的身份处理；保留旧 trace 写向新单元可能改变算法含义。

**停止条件：** 结构诊断提升而功能和收益不变，停止优化该代理指标；一阶输出保护不升级成有限步、所有历史、全部回报的保证。

## 7. 分阶段推进，而不是扩大全排列

| 阶段 | 产物 | 放大条件 | 修订/停止条件 |
|---|---|---|---|
| 0 接口与可学性 | 忠实性检查、手算例、强简单基座、泄漏检查 | 接口可信且任务有诊断机会 | 基座不忠实、所有控制不可学、观察泄漏 |
| 1 最小机制 | 正交小实验和反例 | 结构预测在预定人口中成立 | 更简单解释已充分、反例击中主张 |
| 2 开发选择 | 完整候选/种子/任务矩阵 | 选择规则冻结且强基线齐全 | 按最快完成前缀挑冠军、补调看过的测试 |
| 3 独立确认 | 新种子/任务/长跨度、区间与成本 | 达到预定效应与资源标准 | 关键区间不支持、收益仅开发集存在 |
| 4 长期使用 | 新变化、回访、资源增长和失效记录 | 能持续适应且成本可接受 | 忘记旧能力、不能学新能力、成本失控 |

停止某个机制解释，不等于否定整个研究方向。每次迭代产出一张研究卡和一条决策记录：**问题 → 最强替代解释 → 唯一主改动 → 可观测预测 → 完整人口 → 扩大/修订/停止规则**。协议冻结后发现新假设，登记下一版本；运行中的协议与原始失败保留。

这些流程建议与 [Empirical Design in RL](https://jmlr.org/papers/v25/23-0183.html) 的实验设计思想相接，但本页具体拆分与停止规则是工作台的综合建议，不冒充所有来源共同给出的定理。
