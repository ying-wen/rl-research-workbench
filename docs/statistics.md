# 让统计回答协议中的问题

先定义估计对象，再选汇总方法。主结果通常是“对预定任务分布和独立训练随机性，某一固定算法的部署收益差”。已选配置的性能、给定预算下完整搜索过程的性能、某一个已训练策略的执行性能，是不同对象。

## 开跑前固定六件事

1. **总体与单位**：任务来自固定清单还是总体抽样？独立单位是一次训练、一条生命期还是一个预训练再适配过程？一个策略的许多测试回合不增加训练样本数；同一生命期的多个窗口不是独立生命期。
2. **主指标**：原始回报、累计收益、平均奖励率、达到阈值的时间或有明确定义的成本效用；指定窗口、权重和改善方向。
3. **比较**：一个主要候选与主要对手，最小有意义差异 δ；其他比较标为辅助或探索性。
4. **随机性与配对**：环境情景、初始化、探索、回放与评估分别记录 RNG；事前定义配对键。
5. **样本与停止**：依据试点变异、δ 和所需精度规划数量；预定固定样本或合法的序贯规则，不“跑到显著为止”。
6. **失败与缺失**：崩溃、预算超限、基础设施故障、未完成分别怎么计入；该规则不得看结果后改变。

## 配对必须配到外生情景

若两方法面对相同初始条件和外部扰动，可分析 `D_i = score_candidate_i - score_baseline_i`。同 seed 数字并不保证同情景：不同动作可能改变状态，不同随机调用数会使 RNG 错位。最可靠的可行情景是在环境允许时按时间或事件身份索引外生噪声，并将其与动作采样 RNG 分开。此设计不要求两条闭环轨迹相同。

匹配后仍应检查协方差；正相关才可能降低差值方差。若自然配对不存在，使用独立样本分析；不能事后为区间变窄而重新配对。跨多个任务时优先先在任务内定义效果，再按事前权重汇总。

## 调参、选择与确认

| 层次 | 可做什么 | 不可把什么当作结论 |
|---|---|---|
| 开发 | 查错、探索机制、选择搜索空间和指标 | 已反复查看的数据不能保持“未知测试”身份 |
| 选择 | 固定搜索规则、预算、checkpoint 规则后选配置 | 最高开发均值不是该配置的无偏性能估计 |
| 确认 | 锁配置后用新训练种子/任务/生命期估计 | 失败后改代码再复用同一测试集不能称独立确认 |

每个算法完整调参，并同时报告交互、计算与评估成本。公开默认值可以作实践基线，但不能将精调候选与未经合理调试的对手比较后称算法优势。搜索预算相同不一定等于 GPU 小时相同，应明确主预算和其他成本。

独立确认估计所选配置；若主张“这种自动搜索流程在预算 B 下更好”，外层应重复完整选择过程。把同一 sweep 的最大值反复 bootstrap 不能自动消除选择偏差。短预算早停会偏爱早熟方法；先验证短、长期排序的可迁移性。

## 汇总与不确定性

主表同时给各方法值、差值、区间、独立样本数和失败率。均值区间描述期望估计的不确定性，标准差描述运行间离散程度，容忍区间描述运行总体覆盖范围；不要混用“均值±标准差”和置信区间。

跨任务原始回报单位不同，不能无解释直接平均。使用任务内改善量或预先定义的归一化，公开锚点和任务权重，先对每个运行归一化。IQM、性能分布曲线和改善概率可补充总体图景；它们不能抹去关键任务的退化，也不自动获得任务外泛化含义。

bootstrap 应重采样独立训练单位；配对比较重采样整对，持续学习重采样整条生命期。固定任务清单和随机任务总体需要不同的任务层处理。高度相关窗口不能当 IID 样本；只有一条生命期时，时间序列区间依赖额外假设，不能伪装训练间置信区间。

多个候选、终点和任务都尝试后挑显著结果，会放大误报。指定主比较、报告全体探索，必要时采用适合依赖结构的多重比较方法。多个时间点的点态区间不是整条曲线的同时置信带。CI 跨零不证明等效；需事前设定等效界与对应分析。效果统计显著也不保证超过 δ。

## 样本预算与失败处理

试点仅用于估计量级。配对均值差的正态近似规划可用 `n ≈ ((z_(1-α/2)+z_(1-β)) s_D / δ)^2`；小样本、重尾或强非对称时应以合理模拟或稳健分析复核。不要给所有 RL 任务统一指定 3、5 或 10 个种子。

回报无自然下界时不要把失败填零。预先指定有业务含义的失败代价，或同时报告失败概率、条件于成功的表现和敏感性分析。基础设施重跑保留原记录。CLI 的描述性输出和差值摘要是检查入口；无法替代针对实际随机结构、选择过程和失败机制的完整统计分析，更不能自动决定算法晋级。
