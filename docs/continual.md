# 持续强化学习：以完整生命期检验经验的价值

持续运行、非平稳、多任务、长训练、严格 streaming 并非同义词。先说明未来为何持续需要学习，再选择任务序列或开放世界。环境目录提供选型线索，不能用目录条目代替原作者协议和适配验证。

从通用原则进入具体研究时，继续阅读[两个持续学习项目的实验配方](continual-project-playbooks.md)。其中的外部协议草案需要原项目适配与正式运行；目录存在、指标工具可执行和长期效果成立是不同状态。

## 定义一条生命期

协议至少固定总交互预算、agent 与世界各自的初始化/重置规则、观察权限、任务或漂移生成机制、数据访问、评估方式、资源上限。agent 若获知任务 ID、边界或未来变化日程，必须显式标注；隐藏变化仅供研究者分析时，不能在边界触发候选方法专属重置。

将变化分为外生动力学/奖励变化、部分可观测下的信息不足、策略造成的数据分布变化、对手变化和网络学习老化。先用控制区分原因。固定环境中的回报下降可以是可塑性问题，也可能是值估计或 replay 分布改变。

变化轴应拆开：动力学改变动作结果，目标或奖励改变偏好，感知改变观测映射，外生扰动改变噪声；同时变化另做组合实验。phase ID 与隐藏切换时刻可以进入分析事件表，但默认不进入 agent 观察，也不触发方法重置。只有研究对象明确允许边界感知时，才设单独的有边界条件。

## 三类环境的使用路线

| 环境类型 | 首先回答 | 需要防止的误读 |
|---|---|---|
| 可控持续小环境 | 能否跟踪漂移？记忆是否消除状态混淆？ | 隐藏切换标签泄漏；把已知变化时刻当通用能力 |
| 任务序列，如 Continual World/COOM | 保留、迁移、顺序影响和重新获取 | task head、任务 ID 和边界提供的特权；遗忘下降但学不动 |
| 连续世界，如 Forager/AgarCL | 跨长期经验适应，部分可观测和生态变化 | 将自然重生当全局 reset；改变原始世界后仍沿用原 benchmark 名 |

选定官方版本、commit、配置和环境语义，再记录本项目变体。长程预算不靠名字推断；先测成本并确认长期状态、磁盘和内存上界。

## 两组互补的压力日程

**真实非平稳与复现情境**：先用 A→B 分离适应，再用 A→B→A 检查再次遇到旧情境的恢复；加入从未出现的 C 检查新知识获取。随机化次序、持续时长和变化幅度，并在独立生命期隔离开发日程与确认日程。回到 A 不意味着世界和参数恢复旧状态，需区分自然复现与人为 reset。只改善重复 A 不足以证明新 C 上的适应。

**平稳世界中的学习老化**：环境生成规则不变，让 agent 经历不同训练年龄，再在匹配条件下测新可学信号的获取能力。使用 fresh agent、年龄匹配和经验量匹配参照，控制表示、优化状态与数据分布。若探针本身改变奖励或任务，将其记作受控诊断干预；不能同时称整段严格平稳。两组日程分别区分外部变化和内部学习能力衰退，不用一条复杂曲线解释全部原因。

## 在线主评估与诊断分支

主记录遵循时间因果：使用当前可得信息行动，收到结果后记录，再执行该结果触发的学习。奖励目标依赖未来时，分别记录决策时间和目标可得时间。使用未来整条轨迹的均值方差归一化当前输入会泄漏。

在预定检查点复制 agent 与可复制世界，分出“继续学”和“冻结参数”的未来；冻结权重仍可允许递归状态演化，应注明归一化、记忆写入和检索是否继续。不可复制的真实系统使用独立匹配生命期或承认纵向证据限制，不能把两个不同历史段包装成同起点反事实。

旧任务回访使用独立评测副本，禁止回灌主 learner。没有可复现旧任务时，使用限定探针或自然再遇情境，并说明不能据此恢复完整遗忘矩阵。

## 区分学习、存储与检索

在相同经验权限和资源合同下设计 2×2：持久参数更新开/关，跨任务记忆写入与检索开/关。进一步区分只写入、只检索固定库、当前任务搜索和历史压缩。初始预训练模型相同；上游训练随机性未重复时，结论条件于该模型。

关键问题是：过去经历能否改善未用于设计的新未来任务，并且这种改善不能仅由更长当前任务计算解释。报告无历史、随机/错位历史、匹配容量、匹配搜索成本和必要 oracle。资源匹配无法同时满足所有维度时，明确主要约束并报告其余成本。

## 同时报告收益、可塑性和代价

主指标可选完整生命期累计收益或平均奖励率；辅助记录分段收益、变化后损失与恢复、旧任务保留、新任务学习速度，以及参数/优化器/缓存/记忆大小和每步延迟。固定窗口只用于时间诊断，不能当独立样本扩充 n。

恢复阈值、窗口宽度、确认持续时长和计时起点预先定义。到固定终点未恢复可作为删失；算法崩溃或资源超限是另一类失败事件，不能当作普通非信息删失。若报告 regret，给出 comparator 的信息与适应权限；拥有未来信息的 oracle 不能作为同等可部署方法。

遗忘小可能因从未学会。用非平凡习得门槛、新任务 acquisition、fresh agent 和年龄/经验匹配诊断一起解释；激活稀疏、梯度或 rank 变化只是机制指标，需连接实际学习能力。

## 调参与生命期隔离

独立开发生命期可以完整调参；这与偷看同一测试生命期未来是不同问题。若评估的是“只允许当前生命期前 k% 配置，后续部署”，就锁定前缀规则，在其余生命期按该规则评估，并单列前缀成本。不得在后缀失败后重新挑 k、任务序列或终点。

持续学习器内部的在线超参适应可以属于算法，但它只能使用允许的过去，并且元参数也计入开发选择。正式长期结果需要多条完整生命期；只有较早完成的前缀时报告进行中，不据其排名挑选幸存方法。长期方向的退出条件可以是无收益、明显负迁移、资源随时间失控，或机制不再可辨识。
